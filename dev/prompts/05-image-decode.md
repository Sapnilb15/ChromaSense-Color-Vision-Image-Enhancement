# Increment 05: Image decode and validation (filter 1)

**Status:** Standard
**Depends on:** 04
**SRS IDs:** SRS-FR-001, SRS-FR-002, SRS-NFR-004, SRS-FR-007 (decoded sRGB pixels are the baseline for the unchanged-pixel check)

### Main rules

- Add filter 1 only: `decode_1(data: bytes, limits: InputLimits) -> DecodedImage1`.
- Accept only PNG and JPEG, checked from the file content, never from the file name.
- Reject images over 12 megapixels. Do not downscale.

### Capability

Raw upload bytes become 8-bit sRGB pixels, or a `DecodeError` with a reason.

### What may change

- `src/color_engine/color_engine/models.py`: add `DecodeReason`, `DecodeError`, and `DecodedImage1`.
- New files: `src/color_engine/color_engine/pipeline/filter_1_decode/decode_1.py`, `src/color_engine/tests/pipeline/test_filter_1_decode.py`, and fixtures in `src/color_engine/tests/data/samples/`.

### What must stay

- The color rules and their tests from increment 04.

### Implementation notes

1. Models (`derived`):
   - `class DecodeReason(Enum)`: `UNSUPPORTED_TYPE`, `CORRUPT`, `TOO_LARGE`, `TOO_MANY_PIXELS`.
   - `class DecodeError(Exception)` with attribute `reason: DecodeReason`.
   - `@dataclass(frozen=True) class DecodedImage1`: `pixels: NDArray` (height × width × 3, `uint8`, sRGB), `width: int`, `height: int`, `source_format: str` (`"PNG"` or `"JPEG"`).
2. Order inside `decode_1`:
   1. `len(data) > limits.max_bytes` → `TOO_LARGE`.
   2. `PIL.Image.open(io.BytesIO(data), formats=["PNG", "JPEG"])`. `UnidentifiedImageError` → `UNSUPPORTED_TYPE`.
   3. Animated PNG (more than one frame) → `UNSUPPORTED_TYPE`, because input is still images only.
   4. `width * height > limits.max_megapixels * 1_000_000` → `TOO_MANY_PIXELS`, before `Image.load()`. Set `Image.MAX_IMAGE_PIXELS` so that Pillow does not raise its own warning first.
   5. `Image.load()`. Keep `ImageFile.LOAD_TRUNCATED_IMAGES = False`. `OSError` or `SyntaxError` → `CORRUPT`.
   6. `ImageOps.exif_transpose`.
   7. If the image has an embedded ICC profile, convert to sRGB with `ImageCms.profileToProfile` and `ImageCms.createProfile("sRGB")`.
   8. Convert to `RGB`. Drop alpha by compositing on white (`derived`).
3. Fixtures in `tests/data/samples/`, generated by a small script in the test module or committed as small files: a valid PNG, a valid JPEG, a text file renamed `.png`, a truncated JPEG, a PNG header that declares more than 12 megapixels, a JPEG with an embedded Display P3 profile, and a JPEG with EXIF orientation 6.

### Verification

- Valid PNG and JPEG decode to the expected size and `uint8` RGB pixels.
- The renamed text file gives `UNSUPPORTED_TYPE`, the truncated JPEG gives `CORRUPT`, bytes over 10 MB give `TOO_LARGE`, and the over-12-megapixel file gives `TOO_MANY_PIXELS` without allocating the full image.
- The Display P3 JPEG decodes to the expected sRGB values within 2 units per channel.
- The EXIF-rotated JPEG comes out rotated, with width and height swapped.
- `docker compose run --rm dev pytest src/color_engine/tests` passes.
